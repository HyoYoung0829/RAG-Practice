---

## 휴리스틱 평가란 (핵심 개념)

LLM한테 판단을 맡기지 않고, **정해진 규칙이나 통계적 계산식**으로 채점하는 방식.

```python
def exact_match(prediction, reference):
    return {"score": 1 if prediction.strip() == reference.strip() else 0}
```

### LLM-as-a-Judge와 비교

| | LLM-as-a-Judge | 휴리스틱 |
|---|---|---|
| 판단 주체 | LLM (의미/맥락 이해) | 수학적 계산식 |
| 비용 | LLM 호출마다 비용 발생 | 사실상 공짜, 즉시 실행 |
| 일관성 | 매번 살짝 다를 수 있음 | 같은 입력 = 항상 같은 결과 |
| 의미 이해 | 가능 (동의어, 문맥 파악) | 제한적 (표면적 유사도 위주) |

## 4가지 휴리스틱 지표 (같은 레벨의 나열)

원래 기계번역(MT)/요약 연구에서 만들어진 지표들인데, RAG 평가에도 응용돼.

### BLEU (**B**i**L**ingual **E**valuation **U**nderstudy)
기계번역 평가에서 시작된 가장 오래되고 널리 알려진 지표. **정밀도(precision) 중심** — 생성된 문장의 단어/구절이 정답 문장에 **얼마나 포함되는지**를 봄.

### ROUGE (**R**ecall-**O**riented **U**nderstudy for **G**isting **E**valuation)
주로 요약 평가에 쓰임. BLEU와 반대로 **재현율(recall) 중심** — 정답 문장의 핵심 내용이 생성된 문장에 **얼마나 포함됐는지**를 봄.

### METEOR
BLEU의 단점(동의어를 못 잡아냄, 어순 무시)을 보완하려고 만들어짐. 단어의 정확한 일치뿐 아니라 **동의어, 어간(stem) 일치**까지 고려해서, 사람의 평가와 상관관계가 BLEU보다 높다고 알려져 있음.

### SemScore
**임베딩 기반 의미 유사도**를 활용하는 방식 — 표면적 단어 일치가 아니라 문장 전체의 의미 벡터 거리를 계산. [02번 파일](02_LLM_단일출력_평가자.md)의 "임베딩 거리 기반 평가자"와 발상이 같음 (LLM 판단 없이 벡터 거리로 유사도 측정).

## BLEU 내부의 하위 계산 요소 (부가 디테일 — 별도 지표 아님)

n-gram 중첩, 정밀도, 간결성 패널티는 **독립된 평가 지표가 아니라, BLEU 하나를 계산하기 위한 내부 구성 요소**야. 이 셋을 별개의 개념으로 착각하기 쉬운데, 전부 BLEU 계산 과정 안에 속해 있어.

```
BLEU 계산 흐름:
  1. n-gram 중첩 확인    → 생성문/정답문에서 n개 단어씩 묶어서(n-gram) 얼마나 겹치는지 셈
  2. 정밀도(precision) 계산  → 겹치는 n-gram 수 ÷ 생성문의 전체 n-gram 수
  3. 간결성 패널티(brevity penalty) 적용  → 생성문이 정답문보다 너무 짧으면 점수를 깎음
                                        (짧게 써서 정밀도만 높이는 편법 방지)
```

- **n-gram 중첩**: "1개 단어씩(1-gram)", "2개 단어씩 묶어서(2-gram)" 등 비교 단위를 조정하며 얼마나 겹치는지 확인
- **정밀도**: 생성한 내용 중 정답과 맞아떨어지는 비율
- **간결성 패널티**: "그냥 짧게 대충 말해서 정밀도만 높이는" 꼼수를 막기 위한 보정 장치

## 실무 사용 여부

| 항목 | 실무 사용 |
|---|---|
| BLEU/ROUGE/METEOR (원래 용도: 번역/요약 평가) | RAG 평가의 **주력 지표로는 거의 안 씀** — 의미 이해를 못 하고 표면적 단어 일치에 의존하는 한계 때문 |
| RAG 평가에서의 실질적 쓰임 | **저비용 1차 스크리닝**용으로 LLM 평가와 함께 씀 — 명백한 실패(형식 오류, 완전히 다른 답변)를 빠르게 걸러내는 필터 역할 |
| SemScore류 임베딩 기반 지표 | 상대적으로 더 많이 씀 — 의미 유사도를 저렴하게 근사할 수 있어서, LLM 채점 전 단계의 필터로 활용도가 있음 |

### 실무의 일반적인 계층화(layered) 평가 구조

```
1차 필터: 휴리스틱 (규칙/BLEU류) → 빠르고 저렴하게 명백한 실패 걸러냄
2차 필터: 임베딩 거리 → 의미적 유사도 저비용 스크리닝
3차 심층 평가: LLM-as-a-Judge (RAGAS Faithfulness 등) → 뉘앙스가 중요한 최종 품질 판단
```

전량을 LLM으로 채점하면 비용이 크니까, **휴리스틱으로 먼저 걸러내고 남은 것만 LLM에게 넘기는 방식**이 실무 표준에 가까워.
