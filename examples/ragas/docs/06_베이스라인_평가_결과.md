# 06. 베이스라인(나이브 RAG) 평가 결과

> 전체 지도: [00_전체_흐름과_빌드업.md](00_전체_흐름과_빌드업.md)
> 채점 방법론: [05_RAGAS_RAG_파이프라인_평가.md](05_RAGAS_RAG_파이프라인_평가.md)

리랭커를 붙이기 전, 나이브 RAG([main.py](../main.py) + [rag_pipeline.py](../rag_pipeline.py))를 RAGAS로 채점한 기록. 리랭커를 붙인 뒤 이 결과와 비교하는 게 목적.

---

## 파이프라인 설정

| 항목 | 값 |
|---|---|
| 문서 | data/피지컬 AI의 현황과 시사점.pdf (49페이지) |
| 청킹 | `chunk_size=800`, `chunk_overlap=100`, 페이지 단위로 분할 (106개 청크) |
| 임베딩 | `text-embedding-3-small` |
| 벡터스토어 | FAISS (로컬, L2 거리) |
| 리트리버 | `k=4` (유사도 상위 4개) |
| 답변 생성 LLM | `gpt-4o-mini`, temperature=0 |
| 프롬프트 | [prompt/rag-answer.yaml](../prompt/rag-answer.yaml) — 문맥 밖 내용 답변 금지 + 페이지 출처 인용 + 프롬프트 인젝션 방지 |

## 평가 방법

- **평가셋**: PDF를 직접 읽고 수기로 작성한 질문 5개 + 정답(ground truth)
  - RAGAS `TestsetGenerator`(자동 생성)를 먼저 시도했으나, 이 문서 규모(49페이지, 90개 노드)에서
    멀티홉 질문에 필요한 노드 간 관계가 기본 임계값을 못 넘겨 시나리오가 0개로 조용히 실패함
    (10분 소요, 에러 없이 빈 데이터셋 반환). 목적이 "완벽한 데이터셋 구축"이 아니라 "리랭커
    有/無를 같은 기준으로 비교"였기 때문에 수기 평가셋으로 전환.
- **지표**: Faithfulness, Answer Relevancy, Context Precision, Context Recall (RAGAS 4대 핵심 지표)

## 결과

| 질문 | Faithfulness (충실성) | Answer Relevancy (답변 적합성) | Context Precision (문맥 정밀도) | Context Recall (문맥 재현율) |
|---|---:|---:|---:|---:|
| 0. AI 로보틱스 시장 2030년 전망 | 1.00 | 0.00 | 0.00 | 0.00 |
| 1. 피지컬 AI 정의 | 1.00 | 0.80 | 1.00 | 0.00 |
| 2. 피지컬 AI 유형 분류 | 1.00 | 0.83 | 1.00 | 1.00 |
| 3. 피지컬 AI 확산 장애요인 | 1.00 | 0.82 | 1.00 | 1.00 |
| 4. AI 로보틱스 2020→2025 성장률 | 1.00 | 0.00 | 0.50 | 0.00 |
| **평균** | **1.00** | **0.49** | **0.70** | **0.40** |

지표 정의:
- **Faithfulness**: 답변이 검색된 문맥에 근거하는가
- **Answer Relevancy**: 답변이 질문 의도에 실제로 부합하는가
- **Context Precision**: 검색된 문서 중 실제로 관련 있는 비율
- **Context Recall**: 정답에 필요한 정보를 검색이 빠짐없이 가져왔는가

## 질문별 해석

**질문 0. AI 로보틱스 시장 2030년 전망** — 완전한 검색 실패
검색된 4개 문맥이 드론/휴머노이드 시장 얘기뿐이고 정답 근거(2페이지, "643억 달러")는 하나도 없었음. LLM은 "문서에서 확인할 수 없습니다"라고 답해 거짓말은 안 했으나(Faithfulness 1.0), 애초에 필요한 정보를 못 찾아 Precision/Recall 모두 0.0. Answer Relevancy도 0.0인 건 "모른다"는 답이 질문 의도와 의미적으로 안 맞기 때문.

**질문 1. 피지컬 AI 정의** — Precision과 Recall이 갈린 케이스
가져온 4개 문맥은 전부 "정의"와 관련 있었지만(Precision 1.0), 답변은 WEF의 단일 정의만 인용하고 정답이 요구하는 4요소 프레임(AI 모델/비전·센서/엣지·네트워크/제어·액추에이터)은 놓침 → Recall 0.0. 관련은 있어도 정답 커버리지가 부족할 수 있음을 보여줌.

**질문 2. 피지컬 AI 유형 분류** — 정상 작동
검색·답변 모두 정확 (휴머노이드/자율주행차/드론/AGV&AMR 4유형 다 포함). 전 지표 우수.

**질문 3. 확산 장애요인** — 정상 작동
정답 문장을 거의 그대로 인용할 정도로 정확. 전 지표 우수.

**질문 4. AI 로보틱스 2020→2025 성장률** — 질문 0과 동일한 패턴
"모른다"로 답변, Relevancy/Recall 0.0. "AI 로보틱스"라는 포괄적 상위 개념이 벡터 공간에서 드론/휴머노이드 등 구체적 하위 사례들의 벡터에 밀려, 통계가 담긴 문장(2페이지)이 상위 k=4 안에 못 들어온 것으로 추정.

## 종합 및 다음 단계로의 가설

구체적이고 문서에 명시적으로 정리된 질문(2, 3)은 베이스라인이 잘 처리하지만, **포괄적 상위 개념과 문서에 흩어진 구체적 하위 사례를 구분해야 하는 질문(0, 4)에서 리트리버가 약함**. 이게 리랭커를 붙였을 때 개선되는지가 다음 단계의 검증 포인트.
