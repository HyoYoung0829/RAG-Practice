> 전체 지도: [00_전체_흐름과_빌드업.md](00_전체_흐름과_빌드업.md)

[06번 리포트](06_베이스라인_평가_결과.md)의 나이브 RAG에 리랭커를 추가한 뒤, 같은 5개 질문·같은 채점 방식으로 다시 평가한 결과. 청크 크기(`chunk_size`)나 기본 `k` 등 다른 변수는 전혀 건드리지 않고 **"리랭커 유무" 딱 하나만 바꿔서** 비교했다 (다음 단계인 튜닝과 분리하기 위함).

---

## 추가된 설정 (After에만 적용)

| 항목 | 값 |
|---|---|
| 리랭커 | `LLMListwiseRerank` ([langchain_classic.retrievers.document_compressors](../rag_pipeline.py)) |
| 후보 풀 크기 (`fetch_k`) | `k*2 = 8` (베이스라인의 `k=4`보다 넓게 뽑음) |
| 최종 문맥 개수 (`top_n`) | `4` (베이스라인과 동일 — 여기를 맞춰야 "문맥 개수 차이"가 아니라 "리랭커 효과"만 비교됨) |
| 판정 LLM | `gpt-4o-mini`, temperature=0 (리랭커 자체 판단용. RAGAS 채점 LLM과는 별개) |

## 실제 검색 문맥으로 직접 검증한 인과관계

RAGAS 점수만 믿지 않고, `retrieved_contexts`와 답변을 직접 읽어서 "리랭커가 정말 원인인지"를 개별 확인했다.

**질문 4 — 명백한 리트리버 개선 (검증 완료)**
```
베이스라인: "350%" 근거 자체가 문맥에 없음 → "문서에서 확인할 수 없습니다"
리랭커   : "350%" 근거가 문맥에 포함됨 → "...350% 증가했습니다" (정확)
```
베이스라인은 fetch_k=4라 정답 청크가 애초에 후보에 없었고, 리랭커는 fetch_k=8로 넓혀서 그 청크를 잡아냈다. 순수한 **재현율(Recall) 개선**.

**질문 1 — 다른 메커니즘 (검증 완료)**
```
베이스라인: "액추에이터" 근거가 문맥에 있었지만 → 다른 정의(WEF)만 인용해 답변
리랭커   : 같은 근거로 → "두뇌/감각/연결/행동" 4요소 프레임으로 정확히 답변
```
베이스라인도 이미 정답 근거를 갖고 있었다(Context Precision 1.0으로 Before에도 나타남). 리랭커는 "못 찾은 걸 찾아준" 게 아니라 **후보들의 우선순위/구성을 정리해서 LLM이 더 적절한 근거를 골라 쓰게 유도**한 것에 가깝다.

**질문 0 — 리랭커도 못 고친 한계 (예상대로)**
정답 청크가 전체 106개 청크 중 벡터 유사도 **23등**이라, `fetch_k=8`로는 애초에 후보 풀에 들어오지 못함. 리랭커는 "이미 뽑힌 후보 중에서 순서를 다시 매기는" 역할이라, 후보에 없는 문서는 아무리 똑똑해도 꺼내올 수 없다. → **다음 튜닝 단계(청크 크기 또는 fetch_k 조정)의 타겟.**

---

## 알아야 할 한계: RAGAS 채점 자체의 노이즈

질문 0의 Faithfulness가 Before(1.0)→After(0.0)로 떨어졌는데, **두 경우 모두 답변은 "문서에서 확인할 수 없습니다"로 동일**했다. 즉 실제 답변 품질 차이가 아니라 채점 흔들림이다.

원인을 코드로 추적한 결과:
- `evaluate()`에 `llm`을 명시하지 않으면 RAGAS는 내부적으로 `ChatOpenAI(model="gpt-4o-mini")`를 기본 채점 LLM으로 쓰는데, **`temperature`가 지정되지 않아 OpenAI 기본값(샘플링 있음)으로 동작**한다.
- `temperature=0`으로 고정해서 재실행해봐도 이 특정 케이스(사실 주장이 0개인 "모른다" 답변)는 여전히 흔들렸다 — OpenAI API는 `temperature=0`이어도 완전한 결정론을 보장하지 않기 때문(공식적으로 알려진 한계).
- Faithfulness는 "답변에서 주장을 추출 → 각 주장을 문맥과 대조"하는 2단계 LLM 판정인데, **추출되는 주장이 0개인 경계 케이스**에서 특히 불안정해지는 것으로 보인다.

**결론**: 이번 리포트의 수치 중 **Context Precision/Recall의 개선(질문 1, 4)은 실제 문맥을 직접 대조해서 검증된 신뢰할 수 있는 결과**이고, Faithfulness 평균의 하락은 위 노이즈로 인한 것이라 액면 그대로 "품질이 나빠졌다"고 해석하면 안 된다.
